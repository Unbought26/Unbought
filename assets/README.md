# Assets

- `logo.png` — the proposed Unbought emblem, cropped to a square 512×512 tile with its
  white background kept intact so the cobalt elements stay readable on the cobalt footer.
  The site displays it as a rounded white tile (22% corner radius) rather than clipping
  the artwork to a circle.
- `logo-white.jpg` — the original 1408×768 proposed logo artwork, kept as the source file.
- `pledge-poster.png` — poster frame for the pledge video placeholder.
- `unbought-pledge.mp4` — temporary CC0 placeholder clip from MDN's Web Media examples
  (`flower.mp4`, https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4).
  Replace it with your own community pledge film before publishing.
- `unbought-pledge.vtt` — English captions for the placeholder. Update the timestamps and
  transcript when the final film is added.

The visual identity uses the requested palette: `#1E3A8A` (cobalt), `#B44332`
(red-ochre), `#D99B26` (golden amber), `#FAF9F6` (warm off-white), and `#1F2937`
(charcoal).
